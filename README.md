# Elytra

Disparo vertical en un jardín nocturno. Microcosmos es la serie; Elytra, el escarabajo.

## Jugar

Abre [microcosmos.html](microcosmos.html) en el navegador. No hace falta instalar nada.

## Desarrollo

```bash
npm install
npm run dev
```

El servidor queda en el puerto 8080.

## Controles

Flechas o WASD. El aguijón dispara solo. Espacio lanza la espora. En el móvil, arrastra. P pausa. M silencia.
